

****สร้างBuild Update Version****

***เช็คก่อนมีไฟล์อะไรที่จะถูก Commit
git status

git add -A
git status


***สร้าง Tag และ Push ทั้ง branch และ tag พร้อมกัน (สำคัญ! ต้อง commit ก่อน แล้วค่อย tag)***
git commit -m "Bump version to 1.1.67"
git tag v1.1.67
git push origin main
git push origin v1.1.67

***หรือใช้คำสั่งเดียวรวมทั้งหมด:***
git push origin main --tags

****New2026 - ลำดับที่ถูกต้องสำหรับ Build Version ใหม่****

# (ผมแก้ CURRENT_VERSION = "1.1.73" ให้ได้)

git push -f origin v1.1.75
