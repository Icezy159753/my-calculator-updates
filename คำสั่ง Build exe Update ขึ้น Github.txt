Deploy Main_Program ขึ้น GitHub
เวอร์ชันปัจจุบัน: 1.1.106

วิธีง่าย: ดับเบิลคลิก Deploy_GitHub.bat

1. แก้โปรแกรมและบันทึกไฟล์ให้เรียบร้อย
2. ดับเบิลคลิก Deploy_GitHub.bat ในโฟลเดอร์โครงการ
3. สคริปต์เลือกเลขใหม่และตรวจทดสอบให้อัตโนมัติ
4. ตรวจรายการไฟล์ แล้วกด Enter เพื่อเผยแพร่ หรือ N เพื่อยกเลิก
5. รอ GitHub Actions ผ่านครบ จะมีลิงก์ release แสดงท้ายหน้าต่าง

ไม่ต้องแก้ CURRENT_VERSION เองและไม่ต้อง build EXE ในเครื่อง
ถ้าเพิ่ม package ใหม่ ต้องเพิ่ม dependencies และ hiddenimports/spec ให้ครบก่อน
ถ้าแก้ไฟล์ AutoLychee ให้อ่าน AUTOLYCHEE_RELEASE.md และทำตามข้อกำหนด

ดูแผนก่อนโดยไม่ส่งขึ้น GitHub:
Deploy_GitHub.bat --dry-run

สร้างเวอร์ชันทดสอบโดยไม่แก้โปรแกรม:
Deploy_GitHub.bat --version-only

ไม่ถามยืนยันหลังทดสอบ:
Deploy_GitHub.bat --yes

ถ้า push ไม่ผ่านหลังสร้าง commit/tag ให้รัน BAT ซ้ำโดยยังไม่แก้ไฟล์
ถ้า CI build ไม่ผ่าน ให้แก้สาเหตุแล้วเผยแพร่เลขใหม่ ห้ามย้ายหรือลบ tag เดิม

ต้องมี Git, Python พร้อม dependencies และ GitHub CLI ที่ login แล้ว:
gh auth login

ดู build ย้อนหลัง:
gh run list --workflow windows-release.yml -L 3

workflow_dispatch เป็น preview เท่านั้น ไม่ใช้เผยแพร่ release
ตรวจความพร้อม build EXE และทดสอบก่อน โดยไม่เพิ่มเวอร์ชัน/ไม่เผยแพร่:
Deploy_GitHub.bat --check-only

ERROR จะหยุดก่อน commit/push พร้อมชื่อไฟล์และสาเหตุ
WARNING ให้ตรวจ hiddenimports/hook หรือ optional imports ก่อนยืนยันเผยแพร่
