***เช็คก่อนมีไฟล์อะไรที่จะถูก Commit

***สร้าง Tag และ Push ทั้ง branch และ tag พร้อมกัน (สำคัญ! ต้อง push tag ด้วย)**

git push origin main
git push origin v1.1.65

***หรือใช้คำสั่งเดียวรวมทั้งหมด:***
git push origin main --tags
